# Web 通道决策

状态：讨论定案，未实现。需求：PRD W1–W4；安排：Todo #9。

## 背景

原 Web 通道使用第三方包 `@agegr/pi-web` 0.9.0，已移除。

| 项 | 内容 |
|---|---|
| 引入时间 | 2026-09 前，作为开发版 Web 通道，与 TUI 共用隔离 home |
| 移除时间 | 2026-09-10 |
| 移除原因 | 其前端在每次新建会话时显式下发内置工具列表，绕过 settings.json 的 `defaultTools` 白名单，与只读约束冲突 |
| 替代方案 | 自制 cst-pilot-web（本文档即其决策记录） |

## 决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | 自制 cst-pilot-web，不再用第三方页面 | 工具白名单必须由本项目控制 |
| D2 | 维护两套界面实现：现代版（modern）与兼容版（compat） | 现代版用于看新视觉、试动效；兼容版手工重写。不做构建期自动降级，因为降级工具只能转语法，兼容版要避开的多数是 CSS 属性与浏览器 API |
| D3 | 两版共用业务逻辑，只重写渲染层 | 逻辑统一放 `shared/`；组件 props 与事件保持一致，调用方切换版本无需改代码 |
| D4 | 兼容版底线取 2020 年内核（Chromium 86 / 360 13.x 一级） | 覆盖现场主力内核；目标语法 es2020，不加 polyfill |
| D5 | 动效：现代版全量（含 GSAP），兼容版降为 CSS transition 或手写 rAF | 兼容版不追求效果一致，只保证操作有反馈、界面可用 |
| D6 | 服务端用 node 原生 API，仅监听回环地址；分发为 npm 包（server + 静态资源） | 打包分发最省事；cst-pilot 以依赖 + `.cmd` 引入；仅开发版，发行版不含 Web 通道 |

## 兼容版约束

判定标准：2020 年内核不存在的能力一律不用。

| 类别 | 禁用 | 可用 |
|---|---|---|
| CSS | `:is()`、`@layer`、`aspect-ratio`、`color-mix`、容器查询 | Grid、flex 的 gap、CSS 变量、`clamp()`、`position: sticky` |
| JS | 无额外限制 | 目标 es2020 |
