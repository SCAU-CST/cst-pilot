# PRD — cst-pilot 诊断工具链

辅助维修人员上门诊断：机主描述症状，pi Agent 调用只读诊断工具现场定位原因。

## 需求

| # | 需求 | 回答的问题 | 实现 |
|---|---|---|---|
| R1 | 进程盘点：内存 / CPU 占用 Top N | 谁在吃资源 | `sys(proc)` ✅ |
| R2 | GPU 状态：每进程利用率与显存，独显附温度功耗 | GPU 忙不忙 | `sys(gpu)` ✅ |
| R3 | 传感器：温度 / 风扇 / 电压 | 是不是过热 | `sys(sensor)` ✅ |
| R4 | 整机概况：内存 / CPU 总占用 / 页面文件 / 开机时长 | 整体负载如何 | `sys(overview)` ✅ |
| R5 | 开机自启盘点：注册表 / 启动文件夹 / 自启服务，含禁用状态 | 开机拉起了什么 | `startup` ✅ |
| R6 | 事件日志痕迹：错误警告、蓝屏与关机史、应用崩溃、服务故障、登录审计，可查询 | 过去发生过什么 | `eventlog` ✅ |
| R7 | 设备与驱动健康：异常设备、关键硬件现状、外设、指定查询 | 设备和驱动有没有问题 | `driver` ✅ |

存储分析独立成族：目录大小浏览（`ls`）、磁盘空间 / 健康 / 占用扫描（`disk`），✅ 已实现。

## Web 通道需求

| # | 需求 |
|---|---|
| W1 | 高度定制；第三方库可大方引入，打包分发保持简单 |
| W2 | 设计稿走专用设计软件（Figma 类），动效专门设计 |
| W3 | 现代观感：动效精美、UI 极简；每个诊断工具一张卡片 |
| W4 | 老内核大概率可用：底线 2020 年内核（Chromium 86 级） |

落地方式见 [web 决策](design/web/decision.md)：写现代版和兼容版两套界面，逻辑共用，渲染层各写一份。

曾引入 `@agegr/pi-web` 0.9.0 作开发版 Web 通道。动机是绕过未解的 Windows 终端字符渲染问题，提供不经终端的交互路径。与 TUI 共用同一隔离 home，会话互通。

2026-09-10 移除。原因：其前端工具预设会在每次新建会话时显式下发内置工具列表，绕过 settings.json 的 defaultTools 白名单，与只读约束冲突。后续按 Todo #9 自制。发行版不含 Web 通道：官方 pi.exe 无法承载 node 服务端应用，现场也不需要本机 web 服务。

## 约束

- 只读：不写注册表、不改系统配置、不装驱动
- 零宿主安装：只用仓库自带运行时
- 需管理员的能力必须可降级：明确提示，其余能力不受影响
- 单次调用秒级返回；输出结构化（data / notice / error），可直接转述
