## 目标

| 问题 | 数据 |
|---|---|
| 谁在用，用多久 | 身份指纹、会话起止 |
| 用了哪些模型，花多少 | `models[]` 的 provider、model、token、费用 |
| 用了哪些工具，失败几次 | `tools[]` 的调用数、失败数、耗时 |
| 从哪里接入 | 接收端记录的来源 IP |
| 什么环境，哪个版本 | 工具包版本、Windows 版本与架构 |

只采集本工具自身的运行信息。机主文件内容、命令输出、事件日志、对话正文一律不采。不做审计、监控与远程控制，也不替代网关账单。
