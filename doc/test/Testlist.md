# 测试清单

## 测试清单

### Windows 设备

- [ ] 组装机
- [ ] 品牌台式机：联想 / 戴尔 / 惠普 / 方正
- [ ] 笔记本：华硕 / 联想 / 机械革命 / 惠普
- [ ] 一体机
- [ ] 老旧机器（i3/i5-4xxx~7xxx + 机械盘，Win10 世代）

### 操作系统

- [x] Windows 11 家庭版 / 专业版
- [ ] Windows 10 家庭版 / 专业版（1507~22H2 各版本）
- [ ] Windows 10 政府专用版（政采裁剪，无云服务；外设观察：税务UKey、CA Key、国密卡、天擎等安全软件）

### 移动介质（装本项目）

- [ ] USB 2.0 U 盘（低速基线）
- [ ] USB 3.0 / 3.2 U 盘
- [ ] 移动机械硬盘（USB 3.0）
- [ ] 移动固态硬盘 PSSD
- [ ] SD 卡 + 读卡器
- [ ] 文件系统：FAT32（单文件 4GB 上限，发行包 217MB 不受影响）
- [ ] 文件系统：exFAT
- [ ] 文件系统：NTFS

### PE 盘环境

- [ ] 微PE（WePE）
- [ ] FirPE
- [ ] 优启通（EPT）
- [ ] 其他第三方 PE
- [ ] 官方 ADK WinPE（无注入驱动的基线）

# 注意

1. 仅支持 x64，不测 32 位
2. 不支持Win7及以下系统
3. 不支持Linux，MacOS
