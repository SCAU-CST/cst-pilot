# pi-web 浏览器支持清单

注：`@agegr/pi-web` 已于 2026-09-10 移除，Web 通道改为自制 cst-pilot-web（规划中）。
本清单留作自制包的浏览器基线参考，暂不更新。

仅开发版功能（`pi-web.cmd`）。时间点 2026-09。

## 基线（由依赖决定）

| 组件 | 版本 | 最低内核 | 内核发布年份 |
|---|---|---|---|
| Next.js | 16.3.1 | Chromium 111 / Firefox 111 | 2023 |
| Next.js | 16.3.1 | Safari 16.4 | 2023 |
| React | 19.3.0 | evergreen，无 IE | — |
| @xterm/xterm | 6.0.0 | 仅终端面板，111+ 已覆盖 | — |

低于基线不保证：典型失败是新 JS 语法白屏，无报错可查。

## 现场策略

1. 优先引导 Edge：免安装、evergreen，唯一开箱即用的可靠选项。
2. 打不开先换 Edge，再排查，不查 pi-web。
3. 未来若必须覆盖 Chromium 86–109：fork pi-web 降 `.browserslistrc` 重建，另行决策。

## 证据置信度

- 高：Next 16 基线（官方文档 + 核心维护者公告）、Edge/Chrome/Firefox 现状
- 中：360极速X 132（官方页 + 官方社区）、夸克 112（IT之家 2023–24 报道，内核是否更新未跟踪）
- 低：豆包 ~140、QQ 116–123（第三方下载站与社区帖，冲突存在），装机抽查一次再定稿
