# ls 工具说明

列出目录的直接子项（文件 + 子文件夹），按占用大小从大到小排序，每项带大小和占比。本工具以同名覆盖 pi 内置 ls。

## 参数

1. `path`（必填）：要浏览的目录路径
2. `top`（可选）：返回前 N 项，默认 20，上限 50

## 输出字段定义

1. `path`：实际浏览的路径；`totalChildren`：直接子项总数；`totalSize`：子项大小合计
2. `entries`：按大小倒序的子项列表。`type` 为 file / dir；`size` 为人类可读格式；`bytes` 为原始字节；`pct` 为占子项合计的百分比
3. `omitted`：被截断项的汇总（项数 / 大小合计），出现时说明其余为小项
4. `method`：`wiztree-index` 表示走共享账本；`walk` 表示逐文件递归统计
5. `notice`：出现时表示部分子项大小未统计完整（熔断或无权限），所示大小为下界

## 大小引擎

1. 账本路径：目录大小查询 `wz-index` 进程内共享账本。本盘**首次**查询会触发 WizTree 全盘扫描建账，耗时数十秒；之后同盘任意路径秒回。`disk` 的 usage 扫描也会写入同一账本
2. 降级路径：无账本时逐文件递归累计，有两个熔断：最多 stat 50 万个文件、总时长 30 秒。任一触发后大小为下界并输出 `notice`

## 边界情况

1. `pagefile.sys` 等系统独占文件 `statSync` 返回大小 0，工具用账本中的 MFT 字节兜底
2. 符号链接 / junction 一律跳过，防环路
3. stat 失败（权限不足或文件锁定）的项依次尝试：异步补查 → 目录查账本 `dirs` / 文件查账本 `files` → 记 0 并标记不完整
4. UNC 网络路径没有账本，恒走 walk 降级路径
